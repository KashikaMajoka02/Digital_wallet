# 💳 Digital Wallet - Paytm Clone

A full-stack digital wallet application inspired by Paytm. This project replicates core wallet functionalities such as user authentication, balance checks, and money transfers. It is built with Node.js, Express, MongoDB, and a custom frontend.

## ✨ Features

- 🔐 User Signup & Login with JWT authentication  
- 💰 Balance inquiry & real-time updates  
- 💸 Fund transfer between users  
- 🔄 Transaction handling with server-side validation  
- ☁️ MongoDB database integration  
- 📦 RESTful API with Express.js  
- ⚙️ Vercel deployment ready

---

## 🧰 Tech Stack

**Frontend**:
- HTML, CSS, JavaScript

**Backend**:
- Node.js + Express  
- MongoDB with Mongoose  
- JWT for secure authentication  
- Vercel for deployment
